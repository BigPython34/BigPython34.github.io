# Octave Cerclé — Portfolio

A responsive portfolio presenting my experience in front-office engineering, quantitative finance, machine learning and numerical methods.

## Website

Intended address: https://bigpython34.github.io/

## Local preview

No dependencies or build step are required. Open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## GitHub Pages

The repository should be named `BigPython34.github.io`. In **Settings → Pages**, select **Deploy from a branch**, then **main / (root)**. Save; GitHub will publish the site after the Pages build completes.

## Editing

All content, styles and interactions live in `index.html`. Project entries use `data-category` values (`quant`, `ml`, `numerical`) for the filters. Native `<details>` elements contain the longer project descriptions.

The wireframe is a labelled mathematical illustration, not a chart of empirical project results. No analytics, third-party fonts, runtime dependencies or tracking are included.

## Accessibility

Keyboard-accessible navigation and filters, native expandable sections, visible focus indicators, a skip link, reduced-motion support and responsive mobile layouts.
